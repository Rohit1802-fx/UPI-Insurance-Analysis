# UPI Insurance – Power BI Dashboard

This folder contains the Power BI dashboard developed as part of the UPI Insurance Data Analysis Project.

## Dashboard Overview
The dashboard presents an interactive view of UPI transactions and helps explore transaction performance, customer behaviour, transaction failures, and potential fraud patterns.

## Key Areas of Analysis
- Transaction performance and trends
- Region-wise transaction analysis
- Transaction status and failure patterns
- Payment channel analysis
- Merchant category analysis
- Monthly and yearly transaction trends

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
