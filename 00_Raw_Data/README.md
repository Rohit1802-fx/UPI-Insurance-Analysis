# UPI Insurance – Raw Dataset

This folder contains the original datasets used for the UPI Insurance Data Analysis project.

These datasets serve as the foundation for data cleaning, SQL analysis, exploratory data analysis, and Power BI visualisation.

## Dataset Tables
- Customer Feedback Surveys
- Customer Master
- Device Information
- Fraud Alert History
- Merchant Information
- UPI Account Details
- UPI Transaction History

## Purpose
To maintain the source datasets used throughout the project and provide transparency into the data analysis process.
