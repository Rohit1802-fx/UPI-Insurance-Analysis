# UPI Insurance – SQL Analysis

## Project Overview
This project focuses on analysing UPI insurance-related data using SQL. The goal is to understand transaction patterns, customer behaviour, fraud alerts, payment failures, and overall business performance.

## Tools Used
- MySQL
- SQL

## Analysis Performed

### 1. Data Cleaning
- Checked and handled missing values.
- Identified duplicate records.
- Converted columns into appropriate data types.
- Performed data quality checks.

### 2. Exploratory Data Analysis
- Analysed total transactions and transaction amounts.
- Studied monthly transaction trends.
- Examined transaction status and payment channels.
- Analysed customer feedback and satisfaction.

### 3. Fraud and Risk Analysis
- Examined fraud alerts and suspicious transactions.
- Analysed failed and reversed transactions.
- Studied fraud alert resolution patterns.

### 4. Advanced SQL Analysis
- Month-over-month transaction growth.
- Channel-wise transaction failure rates.
- Customer ranking using window functions.
- Hour-wise failed transaction analysis.

## Project Objective
To use SQL to convert raw data into meaningful insights that can support better business decisions, improve transaction monitoring, and understand customer experiences.
